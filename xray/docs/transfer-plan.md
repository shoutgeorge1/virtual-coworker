# Transfer plan

Document how pilot assets move to Virtual Coworker after Phase 1 validates demand.
Do this only when both sides agree — not as a launch requirement.

## Assets George may hold during the pilot

- Vercel project (microsite)
- GitHub repository (or fork)
- Temporary GTM container
- Temporary GA4 property / stream
- Temporary campaign domain or Vercel URL
- Google Ads campaign structure (inside VC’s Ads account once access is granted)

## Transfer checklist (after validation)

1. Confirm client-owned production domain or subdomain
2. Transfer or recreate GTM container under VC ownership
3. Transfer or recreate GA4 property under VC ownership
4. Point domain DNS to the agreed host
5. Hand over GitHub access or export
6. Transfer Vercel project ownership (or redeploy under VC)
7. Document conversion IDs, events, and naming
8. Confirm lead email / CRM endpoints under VC control
9. Remove George’s temporary credentials after confirmation

## What stays out until separately scoped

- Offline conversion imports
- Full Zoho API integration
- Remarketing / Customer Match
- SEO and broader website modernization
- Consolidation of legacy GA4 / cross-domain measurement

## Principle

The pilot should remain transferable, but launch must not wait on asset transfer.
