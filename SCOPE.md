# Scope boundary — External Funnel Audit

## In scope (this product)

| Included | Examples |
|----------|----------|
| Public websites + linked regional domains | `.com`, `.com.au`, `.com.ph` linked from footer |
| Obvious public hosts | `admin.`, `careers.`, `www.` (probe only) |
| Page-load HTML / headers | CMS, forms markup, chat snippets |
| Public tag containers | `googletagmanager.com/gtm.js?id=GTM-…` |
| Public ATS / careers portals | Zoho Recruit careers URL |
| Factual findings + sellable report | `report.html` + evidence in `raw/` |
| Discovery questions for paid deeper work | `DISCOVERY.md` |

## Out of scope (hard stop)

| Excluded | Why |
|----------|-----|
| Form submits / fake leads | Contaminates CRM; unethical without consent |
| Login / password / SSO | Not an external audit |
| Google Ads / Meta / GA admin mutations | Separate engagement; kill-switch territory |
| Email / LinkedIn / cold outreach from Mini | Air owns outbound; Mini ships demos |
| Scraping behind paywalls / authenticated APIs | Not public |
| “Fix it live” on their WP / GTM | Upsell after paid SOW — not this snapshot |

## Deliverable promise

Prospect receives a **public-only snapshot**: stack, tracking posture, CTA paths, contamination risks, and a short list of paid discovery questions. Anything requiring CRM or ad-account access is **Phase 2**.
