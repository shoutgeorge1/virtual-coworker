# Paid Search pilot — command center plan

Turns `xray/` into a **compact pilot operating center** for a $3,000 Google Search
proof of concept (US + Australia employers).

## Pivot

George runs a **parallel acquisition layer**. He does not need to repair WordPress,
legacy GTM/GA4, or rebuild Zoho to launch. Phase 1 answers: can Search produce
qualified employer leads at an acceptable cost?
